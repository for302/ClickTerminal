ClickTerminal 개발 문서

Microsoft Windows Terminal 오픈소스(microsoft/terminal)를 포크해 멀티 AI 도구 통합, 프로젝트 관리, 커스텀 테마를 추가한 개발자 터미널입니다.

추가 기능설명
프로젝트 사이드바개발 프로젝트를 폴더 단위로 관리하고 원클릭으로 터미널 세션을 여는 250px 패널
멀티 AI 도구 통합Claude Code, Codex CLI, Gemini를 프로젝트별로 설정하고 PTY 세션으로 실행
AI 컨텍스트 미터AI 도구의 토큰 사용량을 실시간 10-세그먼트 UI로 표시
커스텀 테마 시스템탭바·사이드바·다이얼로그 전체에 적용되는 테마 엔진 (빌트인 5종 + 사용자 정의)
설정 다이얼로그테마 선택, 플러그인 토글을 위한 전용 ContentDialog

void TabRowControl::ApplyTheme(Color tabBarBg, Color textColor) {
    // 1. 밝기 계산
    float lum = 0.2126f*R + 0.7152f*G + 0.0722f*B;
    bool isLight = lum > 128.0f;

    // 2. 선택/호버 색상 (Dark: +25/+12, Light: -25/-12)
    Color selected = ShiftBrightness(tabBarBg, isLight ? -25 : +25);
    Color hovered  = ShiftBrightness(tabBarBg, isLight ? -12 : +12);

    // 3. 기본 배경
    TabView().Background(SolidColorBrush(tabBarBg));
    CTuxHeaderBorder().Background(SolidColorBrush(tabBarBg));

    // 4. ⚠ 핵심: Resources 딕셔너리에 직접 오버라이드
    //    TabContainerGrid가 ThemeResource를 사용하므로
    //    Background 프로퍼티만으로는 우측 영역이 변경되지 않음
    TabView().Resources().Insert(
        winrt::box_value(hstring(L"TabViewBackground")), bg);
    TabView().Resources().Insert(
        hstring(L"TabViewItemHeaderBackgroundSelected"), selected);
    TabView().Resources().Insert(
        hstring(L"TabViewItemHeaderBackgroundPointerOver"), hovered);
}

5. AI 도구 실행 흐름
